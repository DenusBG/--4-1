# Навчальний проект з Об'єктно-Орієнтованого Програмування (ООП)

Даний репозиторій містить програмну реалізацію навчального проекту на мові **C# (.NET)**, виконаного в рамках вивчення дисципліни «Об'єктно-орієнтоване програмування».

---

## 📌 Про опис програми та функціонал

Програма являє собою консольний додаток для обліку та управління даними з використанням базових принципів ООП (інкапсуляція, успадкування, поліморфізм, абстракція).

**Основні можливості:**
- Створення, редагування та видалення об'єктів системи.
- Збереження та зчитування даних із файлу (JSON / Text format).
- Сортування та фільтрація списку елементів за різними критеріями.
- Валідація вхідних даних користувача.

---

## 🛠 Попередні вимоги

Для запуску та редагування проекту вам знадобиться:
- **Visual Studio 2022** (з встановленим пакетом *.NET desktop development*) або **Visual Studio Code**.
- **.NET SDK** (версія 6.0 або новіша).
